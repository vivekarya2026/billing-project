# HIG Deviation D3

This is a place where we break Apple's standard rules on purpose.

**HIG default:** Tab bar for top-level navigation  
**Our rule:** **No tab bar.** Home plus persistent Add.  
**Why:** Hick's Law. Five tabs is five decisions on every launch for a product with two real destinations.

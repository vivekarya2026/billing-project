# HIG Deviation D1

This is a place where we break Apple's standard rules on purpose.

**HIG default:** 44×44pt minimum touch target  
**Our rule:** **60×60pt minimum**  
**Why:** 44 is a floor, not a target. Marguerite's reading glasses and Rafael's cracked screen set the bar. Apple itself uses 60pt on visionOS, so there is precedent. Exceeding a minimum is not a violation.

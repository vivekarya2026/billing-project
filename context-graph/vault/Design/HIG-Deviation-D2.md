# HIG Deviation D2

This is a place where we break Apple's standard rules on purpose.

**HIG default:** System red for alerts and warnings  
**Our rule:** **Red only for destructive confirmation.** Never for bill status.  
**Why:** Rafael has been targeted by shutoff scams. Alarm styling from us is indistinguishable from fraud to him. Bill status is carried in words, never colour.

- [[Aesthetic-Usability Effect]]

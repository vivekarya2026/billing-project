# SEC-PM-003

**Category:** data_protection  
**Owner:** architect  

## What to watch out for

Local-first is the architecture. Every design decision must preserve it, and any server-side component requires explicit re-approval.

> **Note:** These items are identified, not solved. The architect owns the solution.

## Constrains

- [[v2.0 — Cloud / Multi-platform]] — Server components need re-approval per SEC-PM-003

# SEC-PM-002

**Category:** data_protection  
**Owner:** architect  

## What to watch out for

The cloud fallback path sends bill imagery to a third party. Where it runs, what it retains, and how that is disclosed is product-defining, not a vendor choice.

> **Note:** These items are identified, not solved. The architect owns the solution.
